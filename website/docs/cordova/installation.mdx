```shell
npx admob-plus install -p cordova
```

Or via [Cordova CLI](https://www.npmjs.com/package/cordova):

```shell
cordova plugin add admob-plus-cordova --save --variable APP_ID_ANDROID=ca-app-pub-xxx~xxx --variable APP_ID_IOS=ca-app-pub-xxx~xxx
```

### Local development

Use Node.js 20 or newer, then build the plugin from the monorepo:

Remplace `admob-plus-cordova` with desired package name, e.g. `admob-plus-cordova`, `admob-plus-react-native`, `admob-cordova-webview-ad`, etc.
```shell
pnpm --filter admob-plus-cordova build
```

From the Cordova application, remove the installed copy and add the local package:

```shell
cordova plugin remove admob-plus-cordova --nosave
cordova plugin add /absolute/path/to/admob-plus/packages/cordova --nosave \
  --variable APP_ID_ANDROID=ca-app-pub-xxx~xxx \
  --variable APP_ID_IOS=ca-app-pub-xxx~xxx
cordova platform remove android
cordova platform add android@14
cordova prepare android
cordova build android
```

The local package uses `play-services-ads:25.4.0` by default. To override it for a specific
application, pass `--variable PLAY_SERVICES_VERSION=25.4.0` when adding the plugin.

`com.google.android.gms:play-services-ads:$PLAY_SERVICES_VERSION` is available for configuration,
the default is `--PLAY_SERVICES_VERSION=25.4.0`.

When using with other plugins and encountering errors, set `AndroidXEnabled` to `true`.


```xml title="config.xml" {3}
<widget>
    <platform name="android">
        <preference name="AndroidXEnabled" value="true" />
    </platform>
</widget>
```

Or add the following plugins for `Cordova<9`,

```sh
cordova plugin add cordova-plugin-androidx
cordova plugin add cordova-plugin-androidx-adapter
```

### Proguard

Add these rules to your proguard configuration:

```
-keep public class admob.plugin.ads.** {
  public *;
}
```

Set `deployment-target` and `SwiftVersion`,

```xml title="config.xml" {3-4}
<widget>
    <platform name="ios">
        <preference name="deployment-target" value="13.0" />

    </platform>
</widget>
```

Run `cordova platform remove ios` then `cordova platform add ios` to take effect.

Cordova iOS 8 installs the Google Mobile Ads SDK through Swift Package Manager. The plugin declares the package in `Package.swift`, so no CocoaPods installation or repository update is required.
